Когерентная логистическая система на базе ядра TAT-7 для автоматизации склада.

## Интеграции
- 1С, Excel, GigaChat, Битрикс24, Честный знак

## Экосистема TAT

| Репозиторий | Назначение |
|-------------|------------|
| [TAT-ROOT](https://github.com/maratsultanov2/TAT-ROOT) | Архитектура, теория, бенчмарки |
| [TAT-ONE-TAP](https://github.com/maratsultanov2/TAT-ONE-TAP) | Память для LLM, TAT-DIFF |
| [TAT-DEMO](https://github.com/maratsultanov2/TAT-DEMO) | Визуализация, демо |
| [TAT7-logistics](https://github.com/maratsultanov2/TAT7-logistics) | Промышленный прототип |
